# 画面と用語

vocabOps の画面ごとにできることと、画面に出てくる言葉の意味、コマンドをまとめる。アプリの考え方と動かし方は [README](../README.md) を、設計の詳しいことは [00-overview.md](00-overview.md) から始まる設計の資料を見る。

## 画面

画面の上の切り替えで、4つの画面を行き来する。

### 文生成

- 言語を選び、言いたいことを日本語で入れると、手札語彙文と拡張語彙文の2つを作る。状況（例：同僚との雑談）を書くと、それに合う言い方になる。
- 文を作るのは裏のワーカーなので、送ってから結果が出るまで、少し待つ。
- それぞれの文に、実際の意味（文が実際に伝えている日本語訳）と、何をどう言い換えたかの説明が付く。拡張語彙文では、手札外語彙の語に色が付く。
- 文の中の語をタップすると、読み上げる。「▶」を押すと、文全体を読み上げる。
- 下にスクロールすると、履歴（これまでの文生成）が並ぶ。1回分ずつ削除できる。削除した回は、語彙更新の材料からも外れる。

### 語彙

- 言語ごとに、手札語彙とノーカン語彙の一覧を、品詞ごとに見る。語をタップすると読み上げる。
- 今の増減モードと、次の語彙更新までの文生成の回数を見る（増減モードは設定の画面で変える）。
- 最近の語彙更新で、足した語と外した語を見る。

### Ops

- **概要**：次の語彙更新までの回数、最後の語彙更新、今の手札語彙の数、手札語彙の数の移り変わりのグラフ、語彙更新の一覧、次の語彙更新の材料（追加候補の集計、削除候補に近い語）を見る。
- **動きの記録**：文生成・語彙更新・ワーカーの動きを、新しい順に見る。
- **語彙更新の画面**（語彙更新の一覧から開く）：1回の語彙更新のステップ（追加候補の集計、LLM の順位付け、削除候補の判定、更新案、語彙更新検証、反映）ごとの結果を見る。語彙更新検証では、原文・今の手札語彙文・提案語彙文・判定を1組ずつ見られる。
- 画面は自動では更新しない。開いたとき、「更新」を押したとき、タブに戻ったときに新しくなる。

### 設定

言語ごとに、次のものを選ぶ。変えるとすぐ保存される。

| 設定 | 内容 |
|---|---|
| 読み上げの声 | ブラウザにある声から選ぶ。「自動」は、地域が合う声・高品質の声を優先して選ぶ |
| 拡張語彙文の手札外語彙 | 拡張語彙文で使ってよい、手札外語彙の語の数（1〜10） |
| 増減モード | 語彙更新で、手札語彙の数を増やす・変えない・減らすのどれにするか。「減らす」は、削除候補が出てから選べる |
| 語彙更新の幅 | 1回の語彙更新で増やす・減らす語数と、入れ替える語数の上限（3・4・5 語） |

## 用語

| 言葉 | 意味 |
|---|---|
| 手札語彙 | 話すときに使う、あなた専用の語彙。言語ごとに持ち、語彙更新で少しずつ最適化される |
| ベースライン | 最初の手札語彙。`docs/baseline/` にある |
| ノーカン語彙 | a・the・and のような、文法のための語。手札語彙には数えず、いつでも使える |
| 手札外語彙 | 手札語彙にもノーカン語彙にもない語 |
| 手札語彙文 | 手札語彙とノーカン語彙だけで作った文 |
| 拡張語彙文 | 手札語彙とノーカン語彙に、手札外語彙の語を数語まで足して作った文 |
| 実際の意味 | 文が実際に伝えている意味の日本語訳。元の言いたいことと比べて、どこまで意味が残ったかを見るためのもの |
| 文生成 | 言いたいことから、手札語彙文と拡張語彙文を作る1回の処理 |
| 語彙更新 | 文生成の履歴をもとに、手札語彙に足す語と外す語を決め、確かめて反映する1回の処理。言語ごとに、文生成 30 回ごとに自動で行う |
| 追加候補 | 最近の拡張語彙文に出てきた手札外語彙の語。LLM が、話すときに役に立つ順に順位を付ける |
| 削除候補 | 手札語彙に入ってから長い間、文生成で使われていない語 |
| 更新案 | 語彙更新で作る、手札語彙に足す語と外す語の案 |
| 語彙更新検証 | 足す語と外す語の両方を含む更新案を、過去の原文で、今の手札語彙文と提案語彙文を作り比べて確かめる工程 |
| 提案語彙文 | 更新案を反映した手札語彙で作った文。語彙更新検証で使う |
| 増減モード | 語彙更新で、手札語彙の数を増やす・変えない・減らすのどれにするかの設定 |
| 語彙更新の幅 | 1回の語彙更新で増やす・減らす語数と、入れ替える語数の上限 |
| 版 | 手札語彙が変わるたびに1つ進む番号。ベースラインが版 1 |

用語のより詳しい定義は、[00-overview.md](00-overview.md) の用語集にある。

## コマンド

| コマンド | 内容 |
|---|---|
| `npm run dev` | 画面と API を起動する（http://127.0.0.1:3000） |
| `npm run worker` | ワーカーを起動する。待ちの文生成と語彙更新を、裏で順に処理する |
| `npm run import-baseline -- <言語コード>` | ベースラインを DB に取り込む。手札語彙は最初の1回だけ、ノーカン語彙は何度でも取り込み直せる |
| `npm test` | 単体テスト |
| `npm run lint` | ESLint |
