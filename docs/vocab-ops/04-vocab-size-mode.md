# 04 増減モードと更新案

## 何をするか

ユーザーが選んだ増減モードに合うように、追加候補と削除候補から更新案を組み立てる。

## 入力と出力

- 入力：増減モード、追加候補（順位つき）、削除候補（順位つき）、今の手札語彙の数
- 出力：更新案（足す語と外す語。足すだけ・外すだけのこともある）

## 増減モード

手札語彙の数に上限は設けない。ユーザーには今の手札語彙の数を表示し、言語ごとに次の3つから選んでもらう。選んだモードは変えるまで保持され、語彙更新のたびに適用される。

| 増減モード（`vocabSizeMode`） | 保証すること |
|---|---|
| 増やす（`increase`） | 手札語彙の数が増えるか、変わらない |
| 変えない（`keep`） | 手札語彙の数を変えない |
| 減らす（`decrease`） | 手札語彙の数が減るか、変わらない |

ユーザーが増減の数を指定するのではなく、語彙更新が候補の状況を見て、実際に足す数・外す数を決める。

## 更新案の例

今の手札語彙が150語のとき：

| 増減モード | 足す | 外す | 更新後 |
|---|--:|--:|--:|
| 増やす | +5 | 0 | 155語 |
| 増やす | +5 | −2 | 153語 |
| 増やす | 0 | 0 | 150語 |
| 変えない | +3 | −3 | 150語 |
| 変えない | 0 | 0 | 150語 |
| 減らす | +2 | −5 | 147語 |
| 減らす | 0 | −3 | 147語 |
| 減らす | 0 | 0 | 150語 |

## 決まったこと

- **増やす**：外すに値する語があれば、足すと外すを組み合わせてもよい。ただし、最終的な数は減らさない。
- **変えない**：削除候補と追加候補を同じ数だけ交換して、手札語彙の中身を良くする。
- **減らす**：削除候補があることを前提に数を減らす。有用な追加候補があれば、純減を保ったまま一部を交換してもよい。
- 削除候補がなければ、無理に外さない。追加候補がなければ、無理に足さない。
- 1回の語彙更新で足す・外す語数には上限を設け、手札語彙が急に大きく変わらないようにする。初期値は足す5語・外す5語（`parameters.md`）。
- 足す語と外す語の両方を含む更新案だけが、語彙更新検証にかけられる（`05-validation.md`）。
- **最初は、増やす（`increase`）だけを選べるようにする。** 削除候補は、手札語彙に入ってから一定回数の文生成があった語からしか出ない（`03-removal-candidates.md`）。使い始めのうちは削除候補が出ないので、変えない（`keep`）と減らす（`decrease`）は意味がない。画面では、この2つを選べない状態で表示し、履歴がたまってから選べるようにする。
