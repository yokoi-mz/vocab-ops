# 06 語彙更新の記録

## 何をするか

語彙更新を1回行うたびに、その内容を記録する。反映したかどうかにかかわらず記録し、語彙の移り変わりと、語彙更新の振る舞いを後から確かめられるようにする。

## 入力と出力

- 入力：1回の語彙更新で使ったもの・作ったものすべて
- 出力：語彙更新の記録（DB）

## 記録するもの

| 項目 |
|---|
| 実行日時、対象の言語 |
| 更新前後の手札語彙と、その数 |
| そのときの増減モード |
| 追加候補の順位と、選定理由 |
| 削除候補と、判定の根拠 |
| 更新案（足す語と外す語） |
| 実際に足した語・外した語 |
| 語彙更新検証を行ったか |
| 語彙更新検証に使った履歴（文生成の番号） |
| 比べた手札語彙文と提案語彙文 |
| 各組の比較判定の結果 |
| 改善・悪化・同等の件数 |
| 反映したか、見送ったかと、その理由 |
| 使ったモデル、プロンプトの版、各種の設定 |
| 実行にかかった費用 |

## 決まったこと

- 手札語彙が変わるたびに、手札語彙の版を1つ進める。どの版にどの語があったかを再現できるようにする。
- 手札語彙の変更履歴には、変更の日時、足した語と外した語、変更の経路（最初のベースラインの取り込みか、語彙更新か）、変更の理由、どの語彙更新による変更かを残す。
- **手札語彙が変わったら、ユーザーに知らせる。** 足した語は、これから覚える語になるため。画面に「最近足した語・外した語」を出す。どの画面にどう出すかは、画面を作るときに決める。
- **反映した語彙更新を元に戻す手段は、今は作らない。** 手札語彙の版と変更履歴を記録しておけば、必要になったときに、前の版の手札語彙に戻す機能を後から足すことができる。なお、調整UIは手札語彙の修正には使わない（調整UIを使うのは、最初のベースラインを作るときと、ノーカン語彙を選ぶときだけ）。
