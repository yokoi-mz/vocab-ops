# 01 文生成の履歴

## 何をするか

文生成のたびに、語彙更新の材料になる情報を記録する。記録していないものは、あとから集計も検証もできない。

## 入力と出力

- 入力：手札語彙での文生成の結果
- 出力：履歴（DB の `generations` とその関連の表）

## 文生成で作るもの

文生成では、毎回2つの文を作る。

| 文 | 使ってよい語 |
|---|---|
| 手札語彙文（`currentSetSentence`） | 今の手札語彙とノーカン語彙だけ |
| 拡張語彙文（`expandedSetSentence`） | 手札語彙とノーカン語彙に加えて、手札外語彙の語を数個まで（上限は `parameters.md`） |

それぞれの文について、旧版と同じく、言い換えた部分や失われたニュアンスを説明する日本語のコメントも作る。

## 記録するもの

| 項目 | 理由 |
|---|---|
| 言いたいこと（原文。ユーザーが入力した本来の意図）、状況、話し手の性別 | 語彙更新検証で、同じ原文から文を作り直すため |
| 手札語彙文・拡張語彙文と、それぞれの実際の意味（日本語訳）・コメント | 追加候補の順位付けで、LLM に文脈として渡すため |
| 各文で使われた語（辞書形に正規化したもの）と、その判定（手札語彙／ノーカン語彙／手札外語彙／固有名詞・数字） | 追加候補・削除候補を集計するため |
| 拡張語彙文で使われた手札外語彙の語 | 追加候補の材料。上の「使われた語」から判定で取り出せる |
| 生成日時 | 記録として |
| 言語ごとの通し番号（その言語で何回目の文生成か） | 語彙更新を何回の文生成ごとに行うかを数えるため。また、各語について「手札語彙に入ってからの文生成回数」（`03-removal-candidates.md`）を数えるため |
| 生成時の手札語彙の版 | 語彙更新検証で、保存済みの手札語彙文をそのまま使えるか（今の手札語彙と同じ条件か）を判断するため |
| 使ったモデル、プロンプトの版、拡張語彙文の手札外語彙の語の数の上限などの設定 | 同上。手札語彙が同じでも、これらが違えば同じ条件とはいえない |
| 費用 | 費用の集計のため |

## 決まったこと

- 文は2つ（手札語彙文・拡張語彙文）。以前の Level A／B を置き換えた。
- 拡張語彙文の手札外語彙の語の数の上限は、設定で変えられる。
- 語は辞書形に正規化して記録する。集計では、1回の文生成につき1回と数える。同じ語が1つの文の中に何回出ても、手札語彙文と拡張語彙文の両方に出ても、その文生成では1回と数える（数え方の詳細は `README.md` の「履歴の2つの使い道」）。
- 語彙更新検証のために作る文（作り直した手札語彙文、提案語彙文）は、この履歴とは**別に**記録する。履歴に混ぜると、追加候補・削除候補の集計が狂うため。

## 未決

- なし（記録する項目の細かい形は、DB の設計で決める）
