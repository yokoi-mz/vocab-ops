# 03 削除候補

## 何をするか

手札語彙から外してもよさそうな語を、LLM を使わず、使用履歴から機械的に見つける。

## 入力と出力

- 入力：今の手札語彙の各語の使用履歴
- 出力：削除候補と、判定の根拠（下の4つの数値）、候補どうしの順位

## 使う情報

語ごとに、次の4つを数える。

| 情報 | 意味 |
|---|---|
| 手札語彙に入ってからの文生成回数（`generationsSinceAdded`） | 手札語彙に入ってから今までに、その言語で行われた文生成の数。使われたかどうかとは関係なく、手札語彙に入っていた期間の長さを、文生成の回数で測ったもの |
| 累計使用回数 | 手札語彙に入ってから今までに、使われた文生成の数 |
| 直近の使用回数 | 直近の一定回数の文生成のうち、使われた数 |
| 最後に使われてからの回数 | 最後に使われてから、何回の文生成があったか |

「手札語彙に入ってから」は、途中で手札語彙の版が進んでも、外されずに残っている限り途切れずに数える。**一度外れてから再び入った語は、再び入ったときに0から数え直す**（外れる前の期間は足さない）。再び入った語は、最近必要になったから入ってきた語なので、入った直後にまた外されることがないようにするため。

### 「使われた」の数え方

**その語が手札語彙に含まれている期間に、手札語彙文か拡張語彙文のどちらかで使われていれば、「使われた」と数える。** 手札語彙文では言い換えで避けられていても、拡張語彙文で使われているなら、その語は必要とされている可能性があるため。外しすぎない、保守的な数え方にする。

| 場合 | 数える先 |
|---|---|
| 手札語彙に**含まれる**語が、手札語彙文または拡張語彙文で使われた | 削除の判定用の使用回数（この文書） |
| 手札語彙に**含まれない**語が、拡張語彙文で使われた | 追加候補用の出現回数（`02-addition-candidates.md`） |

- 手札語彙文と拡張語彙文の両方に出てきても、1回の文生成につき1回と数える。1つの文に何回出ても同じ。
- 語形が変化したものは辞書形に統一して数える。
- 手札語彙に含まれていなかった期間の使用は、削除の判定用には数えない（その期間に拡張語彙文に出たことは、追加候補用に数える）。

## 決まったこと

- **最初は複雑な採点をせず、しきい値で判定する。** 「手札語彙に入ってから十分な回数の文生成があったのに、最近ほとんど使われていない語」を削除候補にする。
- 判定の例（数値は `parameters.md`。どれも仮の値で、実験で調整する）：次をすべて満たす語を削除候補とする。
  - 手札語彙に入ってからの文生成回数が、一定回数以上ある
  - 直近の一定回数の文生成で、使われた回数（手札語彙文・拡張語彙文のどちらかで使われた文生成の数）がしきい値以下
- **最初の手札語彙（ベースライン）は意図して選んだものなので、初期にはあまり外さない。** ベースラインの語は手札語彙に入ってからの文生成回数が0から始まるので、上の条件によって、十分な履歴がたまるまでは自然に守られる。
- **削除候補が複数あるときは、最後に使われてから（一度も使われていなければ、手札語彙に入ってから）の文生成の回数が長い順に外す。**
- **外した語も DB からは消さない。** 将来、拡張語彙文に再び出てくれば、追加候補になる。
- 使用頻度が低いことは、その語が不要だという証明ではない。あくまで「外してもよさそうな語」を見つけるための目安として扱う。
