# 調整できる数値

語彙更新の数値は、コードの設定ファイル（`src/features/vocab-ops/vocab-ops-settings.ts`）に、この表と同じ値で置く。本文（01〜06）には数値を書かず、ここを指す。値を変えたら「変更履歴」に理由とともに残す。

まずは単純な方法で作り、実際の履歴・費用・LLM の判定結果を見ながら、少しずつ調整する。

| 項目 | 今の値 | 状態 | 使う場所 |
|---|---|---|---|
| 語彙更新の実行の間隔 | 文生成 30 回ごと（言語ごと） | 初期方針 | README |
| 拡張語彙文の手札外語彙の語の数の上限 | 5 | 仮 | 01 |
| 追加候補の出現回数を集計する直近の件数 | 30 件 | 仮 | 02 |
| 削除判定に必要な、手札語彙に入ってからの文生成回数 | 90 回 | 仮 | 03 |
| 削除判定の直近の集計期間 | 60 回 | 仮 | 03 |
| 削除判定の使用回数のしきい値 | 0 回 | 仮 | 03 |
| 1回の語彙更新で足す語数の上限 | 5 語 | 仮 | 04 |
| 1回の語彙更新で外す語数の上限 | 5 語 | 仮 | 04 |
| 語彙更新検証に使う履歴の数 | 30 件（直近30件の文生成から無作為に20件、それより前の文生成から無作為に10件） | 仮 | 05 |
| 語彙更新検証の合格の基準（増減モードごと） | 増やす・減らす：悪化が比較した件数の 25% 以下。変えない：改善が悪化より 2 件以上多い | 仮（判定のぶれを測ってから決め直す） | 05 |
| 1回の語彙更新の費用の上限（追加候補の順位付け、語彙更新検証のための文生成、比較判定をすべて含む） | 40 円 | 初期方針 | 02、05 |

参考：通常の文生成は、旧版の実測で1回あたり約0.3〜0.4円。
